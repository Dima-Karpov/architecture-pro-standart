# Цифровая трансформация банка «Стандарт»

Проектная работа спринта 3 курса «Архитектор ПО» (Яндекс Практикум).

Кейсы: открытие депозита онлайн, передача ставок в кол-центр, заявка на кредит онлайн.

## Структура

| Каталог | Содержимое |
| --- | --- |
| `Task1` | Карта IT-ландшафта и схема интеграции приложений с пользователями, включая кредитный процесс |
| `Task2` | Таблица требований FURPS+ в Markdown (депозиты и кредиты) |
| `Task3` | ADR в Markdown: концептуальная архитектура открытия депозитов для MVP, диаграммы C4 (контекст и контейнеры) |
| `Task4` | ADR по передаче ставок в кол-центр и партнёрский кол-центр, список задач по системам, RoadMap на 6 месяцев и на год |
| `Task5` | ADR по заявке на кредит онлайн: функциональные и нефункциональные требования, диаграммы C4 (контекст и компоненты), альтернативы и ограничения |

## Как сдавать

Решения лежат в ветке для пул-реквеста. Ссылка на пул-реквест в `main` уходит на ревью. Репозиторий публичный.
